# Arsitektur — Tabel, filter, aksi, dan paginasi yang seragam

> Status: **SELESAI & TERVERIFIKASI (2026-10-30) — Fase 1–5.** Dokumen ini = sumber kebenaran tabel/filter/aksi/paginasi; aturan ringkas ada di `CLAUDE.md` § "Tabel & daftar". Arahan pemilik: satu desain tabel di semua tempat, kartu bertumpuk di HP, filter berupa dropdown dengan autocomplete (bukan tab/pil), kolom aksi berikon, paginasi seragam. Role user (menu Pelanggan/peran) sengaja dikerjakan terakhir.
> Dasar: `docs/admin-ui-kit.md` (Fase 2–3 lama, 2026-10-21). Dokumen itu menyebut kit sudah selesai; recheck langsung ke kode (SOP langkah 1) menemukan drift di bawah.

| Paginasi tampilan | Elipsis dengan tetangga ±1 + ujung 1 halaman; tak ada mode ringkas di HP. |

## 2. Keputusan desain (asumsi — mohon dikoreksi)
1. **Satu kit** di `components/admin/data-table/` dan `components/admin/ui/`; halaman tak lagi menulis tabel/filter/aksi/paginasi sendiri.
2. **Tabel**: gaya tetap `DataTable` (token `admin-*`). Kolom aksi ditandai `actions: true` (lebar pas, rata kanan, judul "Aksi", di HP pindah ke dasar kartu). Mobile = kartu bertumpuk (sudah ada, dipertahankan).
3. **Filter** = `FilterSelect`: dropdown dengan kotak ketik (autocomplete, WAI-ARIA combobox/listbox, panah/Enter/Esc), pilihan "Semua" untuk mengosongkan. Satu `FilterBar` membungkus kotak cari + semua `FilterSelect` + tautan "Atur ulang". `FilterPills` dipensiunkan (dihapus setelah halaman terakhir migrasi). Filter tetap hidup di URL (bisa di-bookmark); filter mengembalikan ke halaman 1. Tab hanya untuk memisahkan bagian halaman, bukan menyaring data.
4. **Aksi berikon** (`RowActions`, hanya ikon + `title`/`aria-label` teks; satu tempat memetakan ikon di `ACTION_ICONS`): Lihat = `FileSearch`, Edit = `Pencil`, Hapus = `Trash2`, Aktifkan = `Eye`, Nonaktifkan = `EyeOff` (ikon menunjukkan AKSI, bukan status; status tetap di `Badge`). Hanya aksi yang BENAR-BENAR didukung modulnya yang ditampilkan (aturan CRUD lengkap CLAUDE.md: hapus bersemantik aman; nonaktifkan bila dirujuk). Hapus selalu lewat `ConfirmDialog` (modal), bukan `window.confirm`. Server Component tak boleh melempar fungsi ke komponen klien, jadi aksi tautan (`ActionLink`) server-safe, aksi bermutasi (`ApiAction`: hapus/toggle lewat `fetch` + `router.refresh()`) komponen klien yang menerima `url`/`method`/`body` biasa.
5. **Paginasi** (satu `Pagination`): panah-kiri, `1 2 3 … n-2 n-1 n` dengan halaman aktif ±1 (celah satu halaman diisi, bukan elipsis), panah-kanan; di HP ringkas "‹ 5 / 22 ›". Teks "Menampilkan x–y dari N" tetap. Semua daftar yang bisa tumbuh memakainya; **katalog**: API `GET` mendukung `?page&limit` **opt-in** (tanpa parameter = utuh seperti sekarang, jadi picker tak rusak) dan halaman tabel meminta halaman.
6. Tabel publik/campaign (§1) dibahas terpisah di Fase 4 — kit admin memakai token `admin-*` dan CLAUDE.md melarang impor admin ↔ pilgrim; butuh varian bersama di `components/shared/`.

## 6. As-built Fase 3 (2026-10-30)
- **API katalog (13 GET)** — catering, haji, hotels, packages, seasons, tour-packages, tourism-sites, visa, muthowif, flight/routes, flight/schedules, transport/vehicles, transport/trips — memakai `lib/admin/catalogQuery.ts`: **paginasi OPT-IN** (`readCatalogQuery`: `?page=&limit=` memicu paginasi + `meta`; tanpa keduanya = SEMUA baris persis seperti dulu, jadi picker di halaman edit paket/ziarah/penerbangan tak berubah), `q` (≤ 100 karakter, `escapeLike`), `status=active|inactive` (model berisi `isActive`), filter khusus (hotel: kota; haji: jenis), param rusak/asing diabaikan (bukan 500), tiap `orderBy` ber-tie-breaker `id`.
- **UI seragam** `CatalogList` + `CatalogActions` (`components/admin/data-table/`): pencarian (`SearchInput`, jeda 300 ms), dropdown Status/filter, `DataTable`, `Pagination` dari `meta`; state di URL; halaman dengan beberapa tabel memakai awalan param (`useListPage(ns)`: Penerbangan rute `r*` dan jadwal `s*`, Transport kendaraan `v*` dan trip `t*`). Aksi tiap baris: **Edit, Aktifkan/Nonaktifkan, Hapus** (dialog konfirmasi; hapus-aman server: dirujuk → dinonaktifkan dan pesan server tampil); Musim (tanpa `isActive`) hanya Edit + Hapus.
- **Halaman:** 11 halaman/13 tabel + `CategoryManager` (aksi berikon, paginasi di klien karena daftarnya kecil dan datang dari props server). Visa tak lagi dikelompokkan per negara (kolom Negara + pencarian). Rute penerbangan dari "chip" menjadi tabel. `DataTable`: tabel yang lebih lebar dari wadahnya menggulir ke samping (aksi tak terpotong).
- **Bukti:** `test-table-kit` (opt-in paginasi, param rusak, `paginateCatalog` termasuk halaman terjepit, penjaga sumber atas 11 halaman + 13 route: CatalogList/CatalogActions, readCatalogQuery+paginateCatalog, tie-breaker, tanpa `contains` mentah) + 8 mutasi tertangkap; HTTP nyata atas 12 endpoint: tanpa param → semua baris tanpa `meta`, `?page=1&limit=2` → `meta` benar, param rusak → 200, `q=%` literal, **`PUT {isActive}` diterima semua modul**; Chrome + server dev: Hotel (pencarian, filter, paginasi, hapus nyata), Penerbangan (dua tabel), Transport (tab + `tpage`), Kategori Vendor.
- **Belum diverifikasi di browser:** toggle/hapus pada modul selain Hotel dan Vendor (jalur sama, `PUT`/`DELETE` terbukti lewat HTTP), halaman edit pemakai daftar utuh (picker) — dijaga oleh bukti HTTP "tanpa param = semua baris".
